# NEONBEAT - Productora Musical & Label

## Descripción
Landing page para NEONBEAT, sello discográfico y productora musical especializada en música electrónica underground. Presenta artistas del roster, lanzamientos recientes, eventos y redes sociales.

## Tecnologías
- HTML5
- CSS3

## Cómo visualizarlo
Abrir index.html en el navegador web.

## Fecha
Octubre 2026

## Características
- Diseño 100% responsive con Flexbox y CSS Grid
- Paleta de colores cyberpunk neón (magenta, cian, púrpura)
- Tipografía futurista con Google Fonts
- Secciones: Inicio, Artistas, Lanzamientos, Eventos, Redes Sociales
- CSS embebido, sin frameworks
